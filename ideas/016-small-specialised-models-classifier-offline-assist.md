# Small specialised models: classifier, offline assistant, code helper

**The spark** (one or two lines)
A grab-bag of narrow, buildable models: a classifier that labels customer messages (urgent, refund, spam), a tiny offline assistant that runs on a phone or laptop with no internet, and a code helper tuned on our own PHP/XAMPP projects.

**Why it's interesting**
1. Classifiers are the simplest and most commonly bought AI product (for example support-ticket routing).
2. Offline and private models are an active industry area.
3. A code helper is a good portfolio piece.

**First step, if I were to try it**
After Episode 11, build the classifier as the smallest demo, using messages from a shop or clinic we know.

_Also noted: Tamil speech-to-text and time-series prediction (sales, machine failures) are strong businesses but need more data and skills._
